# Spanish Learning Lab

一个面向个人自主学习的西班牙语学习网站。项目以 CEFR 能力目标为参照，从 A1 起步，逐步支持 A1、A2，并为长期达到 B1/B2 建立可持续的学习路径。

> 当前阶段：产品与课程文档初始化。网站代码尚未开始。

## 项目目标

- 把课程、词汇、语法、听力、阅读、口语和写作练习整合到一个学习空间。
- 让每次学习都有明确目标、练习和可检查的结果。
- 记录学习过程、测试结果和错误，帮助安排后续复习。
- 支持自主安排学习时间，不把学习限制在固定的每日打卡流程中。
- 优先保证内容准确、学习路径清晰、进度可追踪，而不是堆砌功能。

## 学习者与课程起点

- 当前起点：A1 初级阶段。
- 第一套课程：30 天、30 课，目标是巩固 A1，并初步接触 A2。
- 每日建议投入：90–120 分钟；单课基础结构按 90 分钟设计。
- 阶段目标：以 A1 能力要求和阶段测评检验学习成果；长期继续向 B1/B2 发展。
- 学习侧重：听力理解、即时表达、常用搭配和真实情境中的语言运用。

## 产品模块

1. **学习首页**：今日学习、继续上次课程、待复习内容和进度概览。
2. **课程中心**：阶段目录、课程详情、学习目标和课程完成状态。
3. **词汇训练**：词义、词性、发音、例句、搭配、辨析和主动回忆练习。
4. **语法学习**：规则讲解、例句、常见错误和针对性练习。
5. **听力与跟读**：音频、听力任务、信息提取和跟读练习。
6. **阅读与写作**：分级文本、理解题、短消息和短文输出。
7. **口语练习**：情景任务、问答、复述和自我录音/评价。
8. **复习与错题**：记录错误、回顾薄弱内容和再次测试。
9. **学习分析**：课程进度、练习表现、能力证据和阶段测评。

具体范围与验收要求见 [产品需求](docs/PRODUCT_REQUIREMENTS.md)。

## 内容与质量原则

- 语言知识应准确，区分通用规则与地区差异。
- 课程完成不等于掌握；掌握程度需要练习和测评证据。
- 练习应提供答案或评价标准，并解释关键错误。
- 课程内容与界面、业务逻辑分离，便于维护和扩充。
- 不以 AI 自动生成内容替代内容校验。
- 不收集与个人学习无关的数据。
