# Product Requirements

## 1. 产品范围

本文件定义个人西班牙语学习网站的功能需求。优先实现一个稳定、可持续使用的 MVP，不一次性实现全部长期构想。

优先级说明：
- **P0**：MVP 必须具备。
- **P1**：核心体验完善后实现。
- **P2**：后续增强。

## 2. 信息架构

建议的主要导航：

- 首页
- 课程
- 词汇
- 语法
- 听力与阅读
- 口语与写作
- 复习
- 学习记录 / 测评

导航名称和页面路径由实现阶段统一确定，不在本规划文档中预设代码路由。

## 3. 功能需求

### 3.1 首页（P0）

展示：
- 当前课程进度。
- 最近学习的课程和继续学习入口。
- 待复习数量或入口。
- 最近学习记录。
- 阶段目标和下一项测评。

验收标准：
- 首页数据来自真实学习记录，不使用固定假数据冒充进度。
- 首次使用时提供清晰的空状态和开始学习入口。
- 用户可以直接进入课程或复习任务。

### 3.2 课程目录与课程详情（P0）

课程目录：
- 展示 30 课及四个阶段。
- 显示每课主题、核心知识和完成状态。
- 支持进入课程和继续未完成课程。

课程详情：
- 展示课程目标、学习内容、例句和练习。
- 按统一学习结构组织模块。
- 能记录模块或课程的完成情况。

验收标准：
- 30 课的标题、顺序和核心知识与课程文档一致。
- 课程内容不硬编码在复杂 UI 组件中。
- 课程未完成、已开始和已完成状态有明确区分。

### 3.3 词汇训练（P0 基础展示与练习；P1 丰富复习）

词汇条目在适用时包含：
- 西语词条。
- 中文释义。
- 词性。
- 名词阴阳性和复数形式。
- 发音或音频资源。
- 例句及中文释义。
- 常见搭配。
- 主题、课程和难度标签。

练习形式：
- 西语到中文的理解。
- 中文到西语的主动回忆。
- 选择题或填空。
- 例句中的词汇识别。

验收标准：
- 词汇显示正确的重音符号和拼写。
- 题目提交后显示答案与解释。
- 练习结果能关联到对应词条。
- 未配置音频时显示明确的不可用状态，不出现无效播放控件。

### 3.4 语法学习（P0）

内容包含：
- 规则说明。
- 适用条件。
- 例句和翻译。
- 易混点或常见错误。
- 对应练习。

验收标准：
- 语法内容按课程或知识点组织。
- 每个核心知识点至少有例句和练习。
- 对地区差异或语境限制作出说明。

### 3.5 听力（P1）

建议流程：
1. 显示听力目标和任务。
2. 播放音频。
3. 完成信息提取或理解题。
4. 提交后查看答案。
5. 按需要查看文本和重点表达。
6. 记录错题或难点。

验收标准：
- 音频来源和使用许可清楚。
- 可以重复播放。
- 文本是否默认隐藏应服务于听力训练。
- 无音频时不提供伪播放体验。

### 3.6 阅读（P1）

支持：
- 与 CEFR 阶段匹配的短文本。
- 阅读理解问题。
- 关键词和表达说明。
- 答案与解释。

验收标准：
- 文本难度、词汇和语法与标注级别基本一致。
- 引用或改编材料应记录来源和授权状态。
- 不以中文逐句翻译取代阅读理解训练。

### 3.7 口语与写作（P1）

口语任务：
- 主题或生活场景。
- 表达目标和提示。
- 可选示例回答。
- 自我评价清单。
- 后续可加入录音和 AI 辅助反馈。

写作任务：
- 写作场景、长度建议和表达目标。
- 提交后可对照示例或评价标准复盘。
- 记录常见错误。

验收标准：
- 没有接入可靠语音识别或 AI 服务时，不显示虚假的自动评分。
- 自我评价与自动评分明确区分。
- 允许记录学习者自己的表达和修改版本。

### 3.8 练习与测评（P0 基础练习；P1 阶段测评）

- 支持选择题、判断题、填空等适合自动判定的题型。
- 提交后展示结果、答案和解释。
- 阶段测评节点：Day 7、Day 15、Day 23、Day 30。
- 最终测评按听、说、读、写组织，但必须明确哪些部分实际可测、哪些部分需要自评或人工评价。

验收标准：
- 题目答案和判分规则可追溯。
- 测试结果记录日期、题目范围和得分。
- 不将单次网站测试结果直接等同于官方 CEFR 认证。

### 3.9 复习与错题（P0 基础记录；P1 自动安排）

- 记录错误题目及关联知识点。
- 支持从错题返回原课程或词条。
- 支持再次练习并保留练习历史。
- 后续可加入间隔复习调度。

验收标准：
- 错题来源清楚。
- 再次答对不会抹去此前的错误历史。
- 复习安排规则透明。
- 复习算法尚未确定前，不要自行宣称使用了某种成熟算法。

### 3.10 学习记录与分析（P0 基础记录；P1 分析）

记录：
- 已学习课程。
- 练习次数和结果。
- 错题与重做情况。
- 阶段测评结果。
- 学习时间（如果实际实现可靠计时）。

展示：
- 课程完成进度。
- 各阶段学习情况。
- 常见错误或薄弱知识点。
- 随时间变化的表现。

验收标准：
- 图表只展示真实记录。
- 样本不足时明确说明，不作过度推断。
- “学习活动”“练习正确率”和“能力水平”是不同指标。

## 4. 非功能需求

### 易用性
- 桌面和手机浏览器均可使用。
- 主要学习流程操作简单。
- 西语重音符号和特殊字符显示正确。
- 练习控件有清楚的键盘和触屏交互。

### 可访问性
- 文本有足够对比度。
- 控件有可理解的名称。
- 重要状态不能只靠颜色表达。
- 支持键盘完成主要流程。

### 可靠性
- 学习记录应在页面刷新后保持。
- 保存失败时向用户说明，不静默丢失数据。
- 空状态、异常状态和无音频状态有明确反馈。

### 隐私与安全
- 只保存实现学习功能所需的数据。
- 不在客户端暴露秘密密钥。
- 不上传私人学习记录到第三方服务，除非用户明确同意并了解数据流向。
- 仓库当前为公开仓库，不得提交秘密或私人资料。

## 5. MVP 验收清单

- [ ] 可以浏览 30 课目录和四个阶段。
- [ ] 可以打开课程并查看目标、知识和例句。
- [ ] 至少一种自动判分练习可以完整提交并查看解析。
- [ ] 可以记录课程进度。
- [ ] 可以记录错题并再次进入练习。
- [ ] 刷新页面后学习状态仍符合已选定的存储方案。
- [ ] 首页展示真实进度和空状态。
- [ ] 桌面与手机主要流程可用。
- [ ] 项目有可重复执行的测试和构建说明。
