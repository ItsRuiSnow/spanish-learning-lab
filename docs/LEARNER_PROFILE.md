# Learner Profile

> 本文件只保留与西班牙语学习产品直接相关的信息。随着实际学习情况变化，应由学习者确认后更新。

## 1. 当前水平与目标

- 当前起点：A1 初级阶段，已接触基础发音、常用问候、简单句和基础词汇。
- 近期目标：以 A1 标准能力要求和练习/模拟测试作为阶段目标，建立可观察的进步。
- 中期目标：此前规划为约六个月推进到 B1；实际进度应由阶段测评和学习表现决定，不把时间计划当作能力保证。
- 长期方向：继续向 B2 发展。
- 建议学习投入：每日约 90 分钟；30 天强化课程允许按当天情况调整到 90–120 分钟。

## 2. 已知学习特点

- 英语基础较好，可以用英语对比解释部分西语现象，但中文仍是主要讲解语言。
- 不喜欢只有背单词的学习方式。
- 更倾向于把听力、即时表达、常用搭配和语境练习结合起来。
- 希望有明确的阶段目标、课程边界和可观察的学习成果。
- 希望通过 A1 试卷或标准化练习检验阶段学习，而不是只看课程完成数量。

## 3. 已知困难与需要关注的点

- 西语颤音 /r/（尤其词首或 rr）是已知发音难点。练习应从放松、舌尖位置和短促气流开始，避免以用力硬弹作为目标。
- 需要持续训练听辨和口语即时调用，不能只通过阅读语法解释判断掌握程度。
- 动词变位、性数一致、介词和自然搭配需要通过分阶段练习反复巩固。

以上是当前已知情况，不代表对全部语言能力的完整测评。网站应通过实际练习持续更新学习记录。

## 4. 内容与语言偏好

- 解释语言：中文为主。
- 目标语言：西班牙语。
- 地区方向：以拉丁美洲常见用法为主要学习参考；出现地区差异时明确标注国家或地区，不将其混为一谈。
- 例句要求：自然、常用、符合当前学习级别，并提供中文释义。
- 发音要求：提供清楚的音节、重音和发音提示；有条件时提供可靠音频。
- 练习要求：先让学习者尝试，再给答案与解释；尽量结合真实情境。

## 5. 网站应如何适配

- 每课明确说明“学完后能做什么”。
- 把新知识放入可理解的例句和对话，而不是孤立列规则。
- 让听力和输出任务贯穿课程。
- 提供错误记录和再次练习入口。
- 对发音难点提供循序渐进的训练，不要求一次达到母语者水平。
- 允许学习者调整每日学习量，不因未按日历完成而清空进度。
- 不根据学习者自我感觉直接宣称达到某个 CEFR 等级。
