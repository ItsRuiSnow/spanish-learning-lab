# Open Questions

本文件记录尚未确认的产品和技术决策。Codex 不应把建议方案当作已批准的决定。

## 1. 技术栈

**状态：待确认**

需要决定：
- 前端框架与语言。
- 样式方案和组件策略。
- 是否需要服务端。
- 测试工具与代码质量工具。

决策原则：优先选择维护成本低、适合个人长期迭代、Codex 容易验证的方案。先检查项目实际状态，再给出有依据的建议。

## 2. 学习数据如何保存

**状态：待确认**

需要决定：
- 是否只在当前浏览器保存。
- 是否需要登录和跨设备同步。
- 是否需要导出/导入备份。
- 数据丢失时如何恢复。

这是重要决策：学习者希望随时自主学习，但“跨设备使用”和“单设备本地保存”是不同需求。

## 3. 部署与访问

**状态：待确认**

需要决定：
- 网站部署到哪里。
- 是否需要公开访问链接。
- 是否需要离线使用。
- 是否使用自定义域名。

## 4. 音频与发音资源

**状态：待确认**

需要决定：
- 使用浏览器语音合成、录制音频还是外部音频资源。
- 目标口音和地区变体如何标注。
- 是否需要慢速播放、逐句播放和跟读录音。
- 音频版权与来源如何记录。

不能在没有真实音频资源时显示有效播放的假象。

## 5. A1 阶段测评标准

**状态：待确认**

学习者希望以 A1 标准试卷或考试作为目标，但尚未确认具体采用哪一种考试体系。

需要决定：
- 是否以 DELE A1 作为主要参照。
- 是否同时参考 CEFR A1 能力描述。
- 网站内部模拟题是否自编。
- 听、说、读、写各项的评价方式。

网站内部测试不得冒充官方考试或官方认证。

## 6. AI 功能

**状态：后续评估**

可能的用途：
- 情景对话。
- 句子和短文反馈。
- 口语转写与表达建议。
- 根据错误生成额外练习。

需要评估 API 成本、密钥管理、数据隐私、输出可靠性和用户是否能关闭 AI 功能。核心课程和练习不应依赖 AI 才能运行。

## 7. 视觉风格

**状态：待确认**

需要决定：
- 整体视觉方向。
- 是否使用西语学习主题视觉元素。
- 明暗主题。
- 桌面和移动端的布局优先级。

建议先保证阅读舒适、信息层级清楚、长时间学习不疲劳，再做装饰性设计。

## 8. 复习调度

**状态：待确认**

需要决定：
- MVP 是否先采用手动复习列表。
- 是否使用固定间隔。
- 如何处理答错、答对和长期未复习。
- 学习者能否调整复习频率。

在规则确认前，先记录错题和练习历史，不擅自宣称某种算法已经实现。
